## 1. 产品概述

### 1.1 产品介绍

Sienovo Marine 是一款面向淡水水域作业的无人船智能遥控软件，与 Sienovo 系列无人船配合使用，主要应用于钓鱼打窝、捕鱼等淡水作业场景，帮助用户更高效、更省力地完成投饵、寻点、起钩等工作。

### 1.2 核心能力

- 4G 远程控制：单条网络链路同步承载控制指令、遥测数据与摄像头画面。
- 自主导航：航点规划、定点投饵、一键返航。
- 实时遥测：GPS 位置、电量、信号、深度、水温、饵料余量。
- 摄像头监控：支持红外夜视、补光灯。
- 健康告警：电机、电池、GPS、舵机、链路等多项实时监测。

### 1.3 系统组成

```text
+--------------+        4G 网络        +--------------+        4G 网络        +--------------+
|  遥控 App    | <-------------------> |   云端服务   | <-------------------> |  无人船终端  |
| (iOS/Android)|                       | (深圳信迈)   |                       |              |
+--------------+                       +--------------+                       +--------------+
```

只要手机与无人船分别能访问 4G / Wi-Fi 网络，即可实现远程控制，作业距离不再受本地射频限制。

## 2. 安装与启动

### 2.1 系统要求

| 平台    | 系统版本           | 推荐机型                                     |
| ------- | ------------------ | -------------------------------------------- |
| iOS     | iOS 16 及以上      | iPhone 12 系列及更新                         |
| Android | Android 11 及以上  | 华为 / 小米 / OPPO / vivo 等主流品牌         |
| 内存    | ≥ 4 GB             | —                                            |
| 存储    | 安装空间 ≥ 200 MB  | —                                            |

### 2.2 获取与安装

- **iOS**：在 App Store 搜索 "Sienovo Marine" 安装，或使用客服提供的 TestFlight 邀请链接。
- **Android**：在应用市场搜索安装，或使用客服提供的安装包（APK）。Android 系统首次安装需信任来源。

### 2.3 首次启动

1. 桌面点击图标启动 App。
2. 首次启动会出现引导页与权限申请。
3. 请按照提示授予以下权限：
   - **定位**：用于显示船与手机位置、规划航点。
   - **相机 / 存储**：用于摄像头预览、截图与录像保存。
   - **网络**：用于与无人船及云端建立连接。
4. 完成引导后进入登录页。

> 提示：若首次启动时拒绝了权限，可前往「我的 → 设置 → 权限管理」或手机系统设置中重新授予。

## 3. 登录与账号

### 3.1 登录方式

App 支持两种登录方式：

- **手机号 + 短信验证码**（推荐）
- **账号 + 密码**

### 3.2 登录步骤

1. 打开 App，进入登录页。
2. 输入手机号或账号，点击「获取验证码」或填写密码。
3. 完成滑块或图形验证（如有）。
4. 点击「登录」进入主界面。

### 3.3 退出登录

进入「我的 → 设置 → 退出登录」，确认后返回登录页。

> 提示：登录成功后默认保持登录态。如更换手机或他人借用手机操作，请记得退出登录。

## 5. 船舶绑定与管理

### 5.1 绑定新船

1. 进入「我的船舶」，点击右上角「+」。
2. 选择以下方式之一绑定：
   - **扫码绑定**：扫描船体上的设备二维码。
   - **手动输入**：填写设备 ID 与激活码。
3. 提交后等待几秒，绑定成功的船会出现在列表中。

> 注意：每艘无人船只能被绑定到一个主账号。如需更换账号，需先在原账号下解绑。

### 5.2 解绑船舶

1. 在「我的船舶」中，长按目标船或进入「船舶详情」。
2. 点击「解绑」，输入二次确认。
3. 解绑成功后该船从列表移除。

> 在线船舶不允许直接解绑，请先关闭船舶电源。

### 5.3 查看船舶详情

点击列表中任意船舶，进入详情页可查看：

- 船舶型号、SN、出厂日期
- 自定义参数（如分组、备注、规格）
- 总航行里程、累计作业时长
- 历史任务汇总

## 6. 实时控制与作业

### 6.1 进入控制中心

1. 在「我的船舶」中找到在线船，点击「连接」。
2. 系统会建立连接，连接成功后状态徽标显示「已连接」。
3. 默认进入控制中心，建议旋转手机为横屏获得最佳操作体验。

### 6.2 控制中心布局

控制中心通常分为三个区域：

```text
+--------------------------------------------------------------+
|                       顶部状态栏                             |
|  船名 | 在线 | 电量 | 信号 | 饵料 | 深度 | 水温 | 断开按钮  |
+----------------------+-------------------+-------------------+
|                      |                   |                   |
|     地图 / 轨迹       |   摄像头实时画面    |    操作面板        |
|                      |                   |  油门、舵向、       |
|                      |                   |  投饵、返航、       |
|                      |                   |  航点、补光等       |
+----------------------+-------------------+-------------------+
```

### 6.3 油门与方向操作

- **油门**：右侧或屏幕右下方虚拟摇杆，向上推加速，向下拉减速；松手自动回到中位。
- **方向**：左侧或屏幕左下方虚拟摇杆，左右控制舵向，松手回到中位。
- **紧急停船**：点击控制面板中央醒目的「停船」按钮，油门立即归零。

### 6.4 一键返航

点击「一键返航」后，无人船将沿安全路径自主返回出发点。返航过程中可随时介入手动控制以中止任务。

### 6.5 失联保护

若手机端与船舶失去连接（如手机进入电梯、信号中断），无人船会自动触发安全策略：

- 短时失联 → 减速悬停。
- 长时失联 → 自动返航或就地停船（视配置而定）。

恢复连接后 App 会自动重新接管控制。

## 7. 自主导航

### 7.1 添加航点

1. 在控制中心地图上长按目标位置，或点击「+ 航点」并输入坐标。
2. 航点列表中会按顺序新增条目，地图上以可识别的图标标记。
3. 重复以上步骤可添加多个航点。

### 7.2 编辑航点

- 拖动航点条目可调整顺序。
- 点击航点旁的「删除」可单独删除。
- 点击「清空航点」一键移除所有航点。

### 7.3 启动自主航行

1. 设置好至少 1 个航点。
2. 点击「开始航行」，无人船将依序前往各航点。
3. 任务过程中，「距目标距离」会随接近目标递减。

### 7.4 中止任务

任务中可以点击「中止」按钮或介入手动操作（推动摇杆）。介入后系统切换为手动控制模式。

> 安全提示：自主航行前请确认水域无障碍物、无往来船只。Sienovo Marine 默认沿直线导航，不具备复杂避障能力。

## 8. 投饵作业

### 8.1 手动投饵

1. 在控制中心点击「投饵」按钮。
2. 船端饵舱将释放设定剂量的饵料，App 顶部状态栏「饵料余量」相应减少。

### 8.2 定点投饵

1. 通过地图设置目标点。
2. 点击「定点投饵」。
3. 无人船将自主导航至目标点 → 自动释放饵料 → 提示任务完成。

### 8.3 饵料余量管理

- 余量为 0 时，「投饵」按钮置灰，需补充饵料后才能继续。
- 出航前请检查饵舱是否清洁、饵料是否潮湿结块。

## 9. 摄像头使用

### 9.1 实时画面

进入控制中心或专门的「摄像头」面板即可看到实时画面。画面会自动适配当前网络状况。

### 9.2 红外 / 夜视

点击「红外」按钮可切换至夜视模式，适合夜间或弱光环境作业。再次点击恢复正常成像。

### 9.3 补光灯

点击「补光」按钮可开启船端 LED 补光灯，配合摄像头使用。注意夜间作业时应避免直射他人或往来船只。

### 9.4 截图与录像

- **截图**：点击相机图标，画面保存到 App 媒体库或手机相册。
- **录像**：点击红色录制按钮开始，再次点击结束并保存。

> 弱网条件下系统会自动降低画面码率以保证流畅，画质可能下降，属于正常现象。

## 10. 健康监测与告警

### 10.1 组件状态

控制中心顶部或健康面板显示以下组件的实时状态：

- 电机 / 螺旋桨
- 电池
- GPS 定位
- 摄像头
- 补光灯
- 饵舱
- 舵机
- 通信链路

每个组件以 4 种状态之一呈现：

| 状态 | 颜色   | 含义                                       |
| ---- | ------ | ------------------------------------------ |
| 正常 | 绿色   | 工作正常                                   |
| 告警 | 黄色   | 工作仍可，但建议关注（如 GPS 精度下降）    |
| 损坏 | 红色   | 该组件不可用，相关功能受限                 |
| 离线 | 灰色   | 无法读取，可能是船端或链路问题             |

### 10.2 告警通知

发生告警时：

- 控制中心顶部弹出告警条幅。
- 严重告警（电量极低、电机损坏等）伴随震动与声音提醒。
- 告警自动写入「任务记录 → 告警记录」。

### 10.3 告警处置建议

| 告警类型     | 建议处置                                       |
| ------------ | ---------------------------------------------- |
| 低电量       | 立即点击「一键返航」，或调头驶向岸边           |
| GPS 异常     | 暂停自主航行，切换为手动控制并驶回开阔水域     |
| 电机 / 舵机异常 | 立刻停船，检查螺旋桨是否被水草或异物缠绕    |
| 链路掉线     | 检查手机网络与船舶天线，必要时等待船舶自动返航 |

## 11. 网络与连接管理

### 11.1 网络要求

- 手机端：Wi-Fi（≥ 5 Mbps）或 4G / 5G 数据流量。
- 船端：内置 4G 模组，需保证 SIM 卡话费及流量充足。

### 11.2 网络切换

App 支持 Wi-Fi 与移动网络的无感切换。短时切换过程中链路会自动重连，期间会出现短暂的「连接中」状态，无需手动操作。

### 11.3 弱网作业

在信号较弱的水库、山区、远距离作业时：

- 摄像头画面会自动降低码率以保证流畅。
- 控制操作可能出现轻微迟滞，请提前预判减速。
- 如长时间无法恢复连接，建议结束作业并将无人船召回。

### 11.4 连接异常排查

| 现象                       | 排查建议                                                     |
| -------------------------- | ------------------------------------------------------------ |
| 一直显示「连接中」         | 检查手机网络是否畅通；尝试切换 Wi-Fi 与 4G                   |
| 船在列表中显示「离线」     | 确认船已开机、电量充足；检查 SIM 卡 / 信号                   |
| 控制延迟明显增大           | 当前网络拥塞，建议靠近基站或更换网络                         |
| 多次「断开 - 重连」反复    | 联系 Sienovo 客服检查云端与终端状态                          |

## 12. 设置与偏好

进入「我的 → 设置」可调整以下选项：

- **摇杆灵敏度**：低 / 中 / 高三档，可按个人习惯选择。
- **横竖屏锁定**：默认跟随系统，可强制横屏作业。
- **声音与震动**：开启 / 关闭告警提示音、震动反馈。
- **单位制**：长度（米 / 英尺）、温度（℃ / ℉）。
- **缓存清理**：清除地图缓存与媒体缓存。

## 13. 安全规范与注意事项

### 13.1 出航前检查

- ☐ 船体无明显损伤，电池电量 ≥ 80%。
- ☐ 螺旋桨清洁、转动顺畅，无异物缠绕。
- ☐ 饵舱清洁、饵料适量。
- ☐ 摄像头镜头清洁，无水渍。
- ☐ 手机电量 ≥ 50%，已连接稳定网络。
- ☐ 已确认作业水域开阔、无明显障碍物。

### 13.2 作业过程

- 请始终保持目视或可视范围内观察无人船。
- 远离往来船只、游泳人员、野生动物聚集区。
- 严禁在禁航区、保护区、繁忙航道作业。
- 注意天气变化，雷雨大风时立即停止作业。

### 13.3 作业后

- 将无人船完整召回岸边再关机。
- 清洁船体与饵舱，避免水生物附着。
- 取出电池、单独存放充电；切勿带电存放。

### 13.4 法律与合规

- 请遵守当地关于无人航行器、水域使用的相关法律法规。
- 私人水域作业前需取得业主授权。
- 涉及水文测绘、巡逻等专业用途时，请确保具备相应资质。

## 14. 常见问题（FAQ）

**Q1：App 一直停留在登录页，怎么办？**
A：检查手机网络是否畅通；若使用账号密码登录，请确认账号正确；如仍无法登录，请联系客服。

**Q2：船在岸边能连上，下水后断了？**
A：可能是岸边 Wi-Fi 切换至 4G 时网络不稳定，建议作业前在岸边切到 4G / 5G 后再下水。

**Q3：船在水中不动，但 App 显示在线？**
A：检查电机健康状态。若状态为「损坏」，可能为螺旋桨被水草缠绕或卡桨，将船召回检查。

**Q4：投饵按钮点了没反应？**
A：检查饵料余量是否为 0，或饵舱状态是否为「损坏」。

**Q5：摄像头画面卡顿严重？**
A：当前网络较差，可关闭摄像头预览继续遥控，或将船开往信号更好的水域。

**Q6：手机熄屏后还能控制吗？**
A：不能。请保持 App 在前台运行；可在系统设置中将屏幕常亮时间调大。

**Q7：能否多人同时控制一艘船？**
A：默认仅允许单一控制端。若有协同作业需求，请联系客服开通多控制端策略。

**Q8：如何更换绑定到另一个账号？**
A：先在原账号下「解绑」，再用新账号「绑定」即可。

**Q9：忘记账号密码了怎么办？**
A：在登录页选择「忘记密码 / 验证码登录」，通过手机号短信验证码重新登录并修改密码。

**Q10：App 升级会影响原有数据吗？**
A：不会。船舶绑定、历史任务等数据保存在云端，升级或重装后重新登录即可恢复。
